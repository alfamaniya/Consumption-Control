# آزمون‌های مرورگر

## آزمون صحت داده

فایل `e2e/data-integrity.mjs` گردش اصلی را در Chromium روی هر دو نسخه چندفایلی و standalone اجرا می‌کند:

1. ثبت دستی کالا و ثبت سابقه ورود
2. تلاش برای ثبت کد تکراری و لغو آن بدون تغییر داده
3. رد ارسال بیشتر از موجودی و حفظ موجودی/تاریخچه
4. ثبت ارسال معتبر و کاهش موجودی
5. بررسی ثبت ورود و خروج در کاردکس
6. رفرش صفحه و بررسی ماندگاری داده‌ها
7. دریافت JSON پشتیبان و اعتبارسنجی موجودی و تاریخچه‌ها

### اجرای محلی

از ریشه مخزن:

```sh
npm install --no-save --no-package-lock playwright
npx playwright install chromium
node scripts/build-standalone.mjs
node tests/e2e/data-integrity.mjs
```

این آزمون از داده‌های موقت و کد کالای ثابت مخصوص تست استفاده می‌کند و مرورگر را با context تازه اجرا می‌کند؛ داده‌های واقعی مرورگر کاربر را لمس نمی‌کند.

## محدودیت پوشش فعلی

بازیابی بکاپ ناقص/قدیمی، شکست ذخیره‌سازی در میانه تراکنش، چندتب هم‌زمان و حذف کالای دارای سابقه هنوز سناریوهای جداگانه و تکمیل‌نشده‌اند. موفقیت این آزمون به‌تنهایی تأیید کامل آمادگی انتشار یا تضمین همه مسیرهای بازیابی نیست.
